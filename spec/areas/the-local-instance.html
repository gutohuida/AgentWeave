Summary

The app itself, running on one machine for one operator: its lifecycle from start to stop, the project workspace it opens, the environment settings and instructions scoped to a project, its own configuration file, the diagnostics that report on its runtime health, the usage it accounts for, and the quiet hours that hold it back from running unattended when told to.
