HomeWork and traceability

7 MUST·7 requirements·15 criteria

Summary

Persistent trace/span timelines for multi-agent work in Hub-backed projects, including automatic correlation of tasks, messages, agent runs, and jobs, trace list/detail APIs, a Hub UI timeline view, and agent traceability instructions.

Requirements

FR-1

SHALL The Hub SHALL persist trace records that group related multi-agent activity under a system-assigned trace identifier.

FR-2

SHALL The Hub SHALL persist span records that describe ordered units of work inside a trace.

FR-3

SHALL The Hub SHALL correlate activity to traces using existing AgentWeave identifiers including task ID, session ID, message ID, and job run ID.

FR-4

SHALL The Hub SHALL expose an authenticated API that lists traces for the current project.

FR-5

SHALL The Hub SHALL expose an authenticated API that returns one trace with its spans and related source records.

FR-6

SHALL The Hub UI SHALL render trace timelines that show correlated activity in chronological order.

FR-7

SHALL Generated AgentWeave instructions SHALL explain how agents preserve trace continuity without manually creating trace identifiers.
