Requirements

FR-1

SHALL The system SHALL accept `runner: opencode` as a valid value in an agent's configuration block in `agentweave.yml`, passing validation without error.

FR-2

SHALL The system SHALL accept the same optional fields for opencode agents as for all other runner types.

FR-3

SHALL The system SHALL serialize opencode agents back to `agentweave.yml` with the correct `runner: opencode` and `model` fields when `generate_agentweave_yml()` is called.

FR-4

SHALL When a user runs `agentweave init` and the session includes an opencode agent, the system SHALL print a reminder that `agentweave mcp-setup` will write `opencode.json`.
