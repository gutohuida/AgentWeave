Quiet hours for agent notifications

change-specarchivedsketch

3 MUST·2 SHOULD·2 MAY·7 requirements·7 criteria·4 tasks

Summary

Notifications interrupt at any hour. This gives each project a quiet window and a graded urgency, so an overnight run stops waking the operator for things that can wait.

Problem

An agent that finishes at 03:00 notifies exactly as loudly as one that needs a decision to continue. The operator learns to ignore notifications entirely, which defeats the only channel the product has for asking a question it cannot answer itself.

Scope

In scope

  • A per-project quiet window
  • Graded urgency per notification
  • A morning digest of everything deferred

Non-goals

  • Per-agent overrides
  • Timezone inference from the host clock
  • Any change to how questions are routed

Requirements

FR-1

MUST A notification raised inside the quiet window is deferred, not dropped.

Losing a question silently is the failure this feature exists to prevent.

FR-2

MUST A blocking question overrides the quiet window and notifies immediately.

A run that cannot continue without an answer is already costing time.

FR-3

SHALL Every deferred notification appears in the next digest after the window closes.

FR-4

SHOULD The digest groups deferred notifications by agent rather than by arrival time.

Six notices from one agent read as one situation, not six.

FR-5

SHOULD The quiet window defaults to 22:00-08:00 in the project's declared timezone.

FR-6

MAY A project may disable quiet hours entirely.

FR-7

MAY The digest may be delivered as a conversation entry rather than a separate surface.

Evidence and coverage limits

Checked

Limits

  • Not tested against a real overnight run

Tasks

  • Record a quiet window per project — Add the window and declared timezone to project settings, and persist it. — satisfies FR-1, FR-5
  • Grade notifications by urgency — Classify each notification as blocking or deferrable where it is raised. — satisfies FR-1, FR-2
  • Deliver the morning digest — Group deferred notices by agent and deliver once when the window closes. — satisfies FR-3, FR-4
  • Let a project opt out, and choose the digest surface — Add the disable switch and the in-conversation delivery option. — satisfies FR-6, FR-7
