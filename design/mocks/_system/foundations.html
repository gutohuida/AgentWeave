Elevation
A four-tier scale built from the existing surface steps
Depth in a near-black UI is read from surface lightness, not drop shadow — a shadow barely registers against --bg, which is exactly what the composer's own removed-shadow note already found. Each tier below is one existing surface step plus the inset --lift-hi highlight already defined for raised controls; nothing is a new value. Hover to feel the lift (--dur-base).
ground · --bg / --rail
0 — Ground
The page itself. Never lifts, never gets a border-radius treatment beyond the shell.
resting · --surface
1 — Resting content
Cards, panels, the composer. .lifted-surface's existing shadow recipe, unchanged.
nested · --surface-2
2 — Nested content
A row or chip inside a tier-1 panel — one step lighter, so containment reads without a border.
overlay · --surface-3
3 — Transient overlay
Menus, popovers, tooltips — the step reserved for things that float above everything else.
Motion
Three durations, one easing — hover each card to trigger it
--dur-fast is direct feedback (press, hover, a value flipping). --dur-base is a state or view change (a row opening, a panel switching). --dur-slow is reserved for things that should read as deliberately unhurried — it is not a bigger version of base, it changes the character of the motion. All three use --ease, a soft expo-out, everywhere; there is no second curve in this system.
--dur-fast150ms
Button hover/press, row hover, focus ring, icon-state swaps.
hover this card
--dur-base250ms
Disclosure open/close, panel/tab switch, empty-state entrance, elevation lift.
hover this card
--dur-slow500ms
Large surface transitions only — a full-panel content swap, never a control.
