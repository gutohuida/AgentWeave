# The sweep set: Hub test files that scan the repository or the UI source instead of importing
# the code they guard (spec `agentweave-s-checks-fit-a-busy-machine`, FR-5). A change selected by
# what it imports never reaches them, so they run as their own fast check:
#
#     py -3.11 scripts/checks/sweep_check.py
#
# A file belongs here when it walks or globs a source tree of this repository (hub/hub, src,
# scripts, the charters) or reads a file under hub/ui/src. Every entry was audited by hand on
# 2026-11-04, starting from probe 2's heuristic list of 34. hub/tests/test_the_sweep_set_is_current.py
# fails when a test file that scans the tree is missing from this list, or when an entry here
# names a file that no longer exists.
#
# Removed from probe 2's list, each read and found not to scan:
#   test_a_write_outside_the_workspace_is_recorded.py  reads one doc and mkdocs.yml
#   test_agent_trigger.py              compares one module path; reads only tmp files
#   test_aw_tool_help.py               one `git diff` of the migrations directory, no scan
#   test_copilot_acp_mapper.py         reads one archived evidence log and a fixture
#   test_database_journal.py           locates alembic.ini and the hub dir to start a subprocess
#   test_dependency_ceilings.py        reads the two pyproject.toml files
#   test_fastmcp_api_contract.py       reads the two pyproject.toml files
#   test_operator_is_a_reserved_agent_name.py  parses one CLI module, src/agentweave/constants.py
#   test_setup.py                      checks the built bundle's index.html exists
#   test_timestamp_serialization.py    reads hub/hub/db/models.py; names hub/ui/src only in prose
#   test_tool_server_pin.py            globs tmp directories only
#   test_ui_build_stamp.py             builds and globs tmp repos; loads one script by path
# Added: test_task_attribution.py (rglobs the hub package via `__import__("hub").__file__`, which
# probe 2's pattern did not match) and the currency test itself (it walks hub/tests).
