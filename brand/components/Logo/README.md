# Logo

The loop: one madder thread that draws the W and loops over itself at the centre, shown here in its lockups, size ladder and clear space.

- **Provide:** a size in px and a ground (light or dark). Pick the file from `assets/Logos`: master drawing at 48px and up, small drawing from 16 to 32px.
- **Lockups:** loop + name (`wordmark` in the app, `display` weight on brand surfaces); loop + name + tagline ("Run your AI factory in the open.") where there is a second line of room.
- **Sidebar head:** loop (16px, small drawing), name, then the live-connection dot. Never drop the dot.
- **Clear space:** a quarter of the mark's width on every side. **Minimum:** 16px.
- **Don't:** recolour, outline, rotate, close the crossing gap, detach the loop, put it on a `madder` ground, or set madder anywhere else in the app.
