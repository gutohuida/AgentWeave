# AppIcon

The ink tile: the madder loop on an `ink-tile` ground with `radius-icon` corners, used for the app window, the taskbar and browser tabs.

- **Provide:** the target size. Use `agentweave-favicon.svg` (small drawing) or the 16/32/48 PNGs for browser tabs; `agentweave-app-icon.svg` (master drawing) or the 180/512 PNGs for the app window, taskbar, Apple touch icon and stores.
- The tile is the same in both themes: it is the product's face, not a themed surface.
- **Don't:** swap the ground for madder or verdigris, add a border or shadow, or crop the tile into a circle.
