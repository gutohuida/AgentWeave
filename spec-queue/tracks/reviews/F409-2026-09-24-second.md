### MEDIUM

**M1. The gate that should stop the build comes after the build.**
- Task 3.1 says "If a row is marked `CHANGED`, stop and re-open D2 … before building". It also asks
  for a d3 run "**before** group 2 lands".
- But 3.1 is numbered after group 2 (2.1 to 2.6).
- An unattended Sonnet window works the list in order. So it would build first and meet the gate
  afterwards. The "before" measurement then needs a revert, which 3.1, unlike 4.1, does not offer.
- Fix 1.

**M2. The picker offers a path that resolves outside the workspace through a link, and it attaches.
Measured, and not named anywhere in the change.**
- The setup: a junction `ws/docs` pointing to `../outside`. `mklink /J` needs no administrator on
  this machine; `New-Item -ItemType SymbolicLink` does.
- `git ls-files --cached --others --exclude-standard`, which is `list_workspace_paths`'s command,
  lists `docs/secret.txt`.
- `isSafeMentionValue` would accept it: there is no at-sign.
- `claude -p 'please look at @docs/secret.txt . …'` produced an `"attachment":{"type":"file"}`, and
  the marker from outside the workspace was in the session transcript.
- So one more agent-shaped route reaches the operator's own mention: a link rather than a name. The
  operator sees a path that looks like a workspace file, which is D10's own argument.
- The Hub already refuses this path elsewhere. `workspace_file.read_workspace_file` treats "a symlink
  resolving outside the workspace" as not in the workspace, so the file tab for `docs/secret.txt`
  says not found, while the picker offers it.
- **Why this is not a bypass of the change:**
  - Creating the link needs a shell call that names the outside path, which the "Workspace only"
    posture judges (B4).
  - An agent with no posture can read the file itself anyway.
- **Where the fix belongs:** it is not text, so it does not belong in F409. It belongs in the listing,
  for example by dropping members whose resolved path leaves the root, the same rule as
  `read_workspace_file`. It sits naturally with F444, which is also about links that leave the
  workspace.
- Fix 3.

**M3. The B5 and B7 halves of the first review's LOW item are still open.**
- D3 and D7 state the ordering rules. R4-8 says "the orchestrator should add the matching sentence"
  to B5.
- `grep` finds no mention of F409, `file_mentions` or neutralisation in either
  `evidence-is-decided-after-the-run-that-recorded-it` or `worker-spend-counts-against-the-budget`.
- **B5 is APPROVED.** It adds a queue origin with a migration, so it can build in the same window as
  this change.
- This change's test 1.1 unknown-origin row pins the default-deny form. But it cannot hold an
  `evidence` row until B5 exists, and a B5 builder that restructures `format_turn_prompt` has
  nothing telling it not to.
- Fix 2.

### LOW

- **L1.** Task 2.3e omits `npm run build` (fix 4).
- **L2.** The Composer insert-effect guard has no test (fix 5).
- **L3.** Which string the skill filter is applied to, and where the slice falls, are left to the
  builder (fix 6). Filtering the full path and filtering the name are equivalent for every value I
  constructed, because stripping the prefix never changes the character before an at-sign except at
  index 0. So this is wording, not a hole.

  make it deliberate.

  turn. That is harmless, and nothing needs to change.
