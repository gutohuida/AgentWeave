Research files, one per day, copied in by the day window from
~/.claude/routines/agentweave-research/out/. Contract: ../README.md

A day may hold more than one file when the routine fired more than once. `<date>.md` is always the
**delivery the day window took**, and any superseded run keeps its clock in the name
(`2026-09-01-run1-0105.md`). Tomorrow's window reads `<date>.md` and nothing else.
