# Build retrospective of Windows notifications for what calls the operator

Document: spec/changes/windows-notifications-for-what-calls-the-operator/spec.json (spdoc-ef873051bab5)
Made: 2026-11-08T21:28:17.221539+00:00

## Lessons

- When a reviewer adds fix tasks that an acceptance-run task needs, the acceptance task must be made to depend on them. Otherwise the flow keeps handing it out and every turn ends in an empty completion and an evidence-only send-back. (cites: spev-0bba6f053bd2, spev-0c6d9eed301f, ttr-dccfb0ad5933)
- Any page-level check in a Windows drive should read the page through WebView2 DevTools, with a dedicated WEBVIEW2_USER_DATA_FOLDER for the scratch window. UI Automation and the shared app-window profile cannot see the page while the operator's own app is open. (cites: ev-0d112ab8653f)
- Specs that close or hand over the app window must say how notices published during the hand-over are delivered, including a close while still on the splash. An acceptance check should ask within 2 s of the close. (cites: ev-71b57869ac46, ev-30fb83227a05, ev-5606dd8a1cac)
- Moving the page onto a new SSE event type also requires adding that type to SSE_EVENT_TYPES in hub/ui/src/hooks/useSSE.ts. A test must push the frame through useSSE, not call the parser directly. (cites: ttr-958d2594bbf3, ev-be76f7810cbe)
- New React Query call sites must bind and use their error, or the test_surface_ceilings ratchet will fail the sweep. (cites: chk-ed17dfda9a37, chk-165be5358ce6)
- Anything the app registers per user (protocol link, Start-menu shortcut, environment) must be rewritten when it does not match the current install. Drives that touch it must save and restore it. (cites: task-9eedcfd62b3b, run-07da9bf98d93)
- Agents running scratch Hubs must check that the port is free and that no hub-*-<port>.pid exists before starting, because concurrent agents share the machine. (cites: run-45ccaa10ae3e, ttr-ef31e24119e0)
- Run worktree tests with PYTHONPATH=src (and hub where needed). The editable install otherwise imports the main checkout. (cites: run-45ccaa10ae3e, run-3b7bd0ed538d)

## What to improve

- [tooling] When a reviewer's amendment adds fix tasks for an acceptance-run task, let it set (or let agents set) the acceptance task to depend on them, so the flow stops handing out a task that cannot progress. (cites: spev-0bba6f053bd2, spev-0c6d9eed301f, run-cb776a10c302)
- [tooling] Let the mender release a blocked task once the stated blocker has merged, or auto-release it. Seven mender turns gave up on the same obsolete block, and the task waited about 14 hours for the operator. (cites: stall-9bf6f26ab95f, stall-e7192a346474, ttr-5047b3cedaee)
- [tooling] Give builders a 'waiting on task X' state that neither queues a review nor needs the operator, instead of the choice between an empty completion and a person-wait block. (cites: run-722c10262f17, run-70eae2cc6945)
- [tooling] Make submit_checkpoint_notes accept a single string for suspicions/warnings, or state the list shape in its error. Notes were lost when agents did not retry. (cites: run-947b4020bd3a, run-cfe6a7f04cd9)
- [code_and_checks] Make worktree test runs import the worktree's own src, either through the check harness or by not relying on an editable install pointing at the main checkout. (cites: run-45ccaa10ae3e, run-dc51ec5f5e3a)
- [code_and_checks] Keep the d1108 drive's DevTools page reading, cross-process window discovery and saved/restored registry state. Make drives refuse a port with an existing hub pid file, and refuse to close windows opened by the operator during a run. (cites: run-07da9bf98d93, run-178a79247fdc, run-45ccaa10ae3e)
- [code_and_checks] Fix or quarantine test_a_slow_share_does_not_freeze_the_hub and test_lifespan_shutdown, which keep failing check gates unrelated to the work. (cites: chk-f68c0240a192, chk-8b8ee5a51e69)
- [specs] In specs for window lifecycle features, list the close-on-splash and first-seconds-after-close cases as explicit criteria with how_to_check timings. (cites: ev-30fb83227a05, ev-5606dd8a1cac)
- [specs] Before tasks are cut, have the spec name the repo's ratchets and allowlists that new UI work must satisfy (n11 query error sites, SSE_EVENT_TYPES). (cites: chk-ed17dfda9a37, ttr-958d2594bbf3)
- [specs] Before the fail-first drive is written, have the spec fix the contract details the drive must target (settings route, page labels/testids, toast launch format), rather than leaving the drive to guess them. (cites: ckpt-c68ba4f543d5, run-487542014d29)
- [staffing_and_running] Start fix tasks that unblock an acceptance run promptly, or assign them to an idle builder rather than one already holding another fix. (cites: ttr-d817fd7ecfe2, ttr-d89aed080e6d)
- [staffing_and_running] Run Windows acceptance drives when the operator is not using the desktop, or tell the operator, because the foreground window, Do Not Disturb and the shared WebView2 profile affect results. (cites: run-3d55eb217605, run-b1ec848a09a2)
