## Lessons

- /traces/totals does not report tool errors. A spec that wants tool errors in conversation totals must also ask for the Hub route to carry them. (cites: ev-4527e0075175, spreq-afa734b640c0)
- Hub timestamps are tz-aware and end in '+00:00', so any drive or client building a since/until query must URL-encode it, or the route answers 422. (cites: ttr-dc40b0f948cf)
- The /traces/totals response wraps its figures under a 'totals' key, and the by-run span list includes the root span. (cites: run-99edf9951867)
- Every new query call site in hub/ui/src must bind and use its error. test_surface_ceilings is a ratchet that refuses any growth. (cites: chk-e38a131706b5, ttr-8ac568ab5d55)
- Any change under hub/ui/src, even formatting, needs scripts/refresh_ui_bundle.py and a commit of the re-stamped bundle. Otherwise the stamp is stale and /health warns. (cites: ttr-f83787d2ab6e)
- A drive's test-id contract should be derived from the mock it targets. A wrapper element cannot also serve as the bar whose box is measured. (cites: ttr-1ea255707d1d)
- Mocks a build task depends on must be on the base branch before the build starts, with any fixtures they need committed. (cites: run-99edf9951867)
- After any send-back, evidence for every requirement must be recorded again at the new commit, not only for the rejected pieces. (cites: ttr-dc9779b1de21, ttr-075702f176f9)
