# Project checks for this repository (AgentWeave), measured 2026-10-24

These are the checks to enter in **Settings → General → Checks** for project `proj-d85a82bf4216`.
They are not configured yet. The Hub runs each command with `cmd.exe` (`shell=True`) in a scratch
checkout of the commit an approval would merge (`hub/hub/project_checks.py`). It removes the Hub's
own `AW_*`, `HUB_*` and `DATABASE_URL` variables first. Each check's timeout defaults to 900 s and
can be at most 3600 s.

## The checks

Enter them exactly as written. `cd hub` and `set PYTHONPATH=src` make each suite import the code in
the checkout being checked. Without them, the suites run against the main checkout's editable
install and test the wrong code. This was verified: from `hub/`, `import hub` resolves to the scratch
tree, and with `PYTHONPATH=src`, `import agentweave` does too.

machine. The UI checks (`npm run lint`, `tsc`, `npm test`) are left out. A scratch checkout has no
`node_modules`, so they would fail or would need `npm ci` (several minutes) on every run. UI changes
remain unchecked by the gate until that is solved.

## Why not to turn them all on at once

When a check fails on a task and the same check also fails on master, the Hub neither passes nor
blames the task. It **holds the approval for the operator** (`hub/hub/requirement_gate.py:1057`,
the PREEXISTING_CHECKS hold). The judgement is per check, not per test. While master is red on a
check, every task in every flow therefore stops for the operator, and a new failure a task adds
inside an already-red suite cannot be told apart from the old ones. Flaky timing tests would also
hold tasks at random.

Recommended order:

1. Make master green on `lint` and `format`. That is five small fixes.
2. Turn on `lint`, `format` and `types`. Together they take under a minute and are deterministic.
3. Add `cli-tests` and `hub-tests` once the project-delete tests are fixed and the remaining
   master failures are fixed or marked as skipped. The Hub suite runs a second time on master
   whenever it fails, so a red task costs about 50 minutes of machine time.
