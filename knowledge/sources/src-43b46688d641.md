# Build retrospective of A traces view with filters, grouping and stats

Made: 2026-11-03T11:19:24.950535+00:00

## Lessons

- When a requirement compares a figure with a list ('opens exactly those runs'), the spec should name the function that computes the figure (here work_tally). The filter must then reuse that function's run set. (cites: ttr-a02e8ae5d06d, spreq-5deffaa20ced)
- A spec that asks for cost per run should name turn_usage.api_equivalent_usd_micros as the settled per-run cost. session_totals holds per-session token figures and no total_cost_usd key. (cites: ev-e40978dccdf9, spreq-480273afbaab)
- An acceptance drive written before the build should only use routes and URL params that already exist. Anything else should be named in the spec as a contract a specific task must add. (cites: ttr-e990792f862e)
- A drive step that needs a stopped or failed run must wait until the run is observed running before stopping it. A fixed sleep races fast models like Haiku. (cites: ttr-d5e2452df253, ev-4138af569b0c)
- A performance requirement such as FR-13 needs its own task owning the slow code path. A shipping task that only measures cannot meet it. (cites: spev-461dda118d59, spreq-9f8e03914006)
- Any new React query call in hub/ui must bind and use its error. test_surface_ceilings caps unhandled query sites at 67 and fails the gate otherwise. (cites: chk-7c6e95431735, chk-ae47317b5893)
- New UI code that builds dates with raw new Date(...) trips the hubTime sweep. Such code needs an EXEMPT entry with a reason, committed with the change. (cites: chk-d2be7126ef6f, ttr-0660960caef3)
- A UI entry point that shows many firings must resolve run ids for exactly the rows it renders. Reusing a route capped at the last 10 records misses most rows on real loops. (cites: ttr-7b9c6c1765f2)
- Tasks that edit the same files (traces.py, TracesPage.tsx) or the committed UI bundle should be sequenced in the spec. Otherwise the second to land needs a merge round. (cites: ttr-db2c5ace449e, ttr-a4b239c2c502)
- FR identifiers are shared across spec documents in this project, so every record_evidence call must name the document. (cites: run-cc780144c463, run-a1c1f63c6995)

## What to improve

- [specs] State the data source for every figure a requirement checks: per-run cost from turn_usage.api_equivalent_usd_micros, build run counts from work_tally. Builders and drive authors should not have to guess. (cites: ttr-e324223d2dc5, ttr-a02e8ae5d06d)
- [specs] Give performance requirements their own implementation task, with the measurement method (backup copy, route, number of calls, load noted) written into how_to_check. (cites: spev-461dda118d59, ev-2b9b66273c84)
- [specs] For each entry point the spec lists, say how the entry point's record maps to a run. Do not leave it to the builder to judge linkability, as happened with job firings. (cites: spev-b009ecda632b, ev-59477a843d6c)
- [specs] Declare dependencies between tasks that edit the same files, or the committed UI bundle, so they land in sequence rather than conflicting. (cites: chk-6ae3614c4c23, ttr-a4b239c2c502)
- [code_and_checks] Run the surface-ceilings ratchet and the hubTime sweep in a fast pre-check before the full hub-tests run. Builders would then see them in minutes rather than after a 30–40 minute gate. (cites: chk-7c6e95431735, chk-d2be7126ef6f, chk-ae47317b5893)
- [code_and_checks] Fix the stale test-id contract in the drive docstring, as QA2 noted on approval. (cites: task-04042920f6d9, ev-4138af569b0c)
- [tooling] Make record_evidence infer the document from the task's own spec document instead of failing when an FR id appears in several documents. (cites: run-c3e867aa4c18, run-b9c1ac091b64, run-403486536543)
- [tooling] Do not discard a nearly finished gate run when main moves. Reuse the passing results whose inputs are unchanged, so tasks do not restart 20–40 minute hub-tests runs. (cites: chk-d692342cc8de, chk-0b7bf7772858, chk-b4cc8197be9e)
- [tooling] Ensure the commit a reviewer checks out is the tree the gate ran on. In TVFGS-2 they differed, and a fixed task was sent back. (cites: ttr-0660960caef3, chk-4e868a25f4b1)
- [tooling] When a mender is dispatched to a loop stall, give it the loop's tasks. The mender found none and gave up. (cites: run-8db065f1337b, stall-f004908068ba)
- [staffing_and_running] Avoid running timing-sensitive verification while several agents' test suites load the machine, or record CPU load with every timing. FR-13 numbers swung from 0.3 s to 4 s depending on contention. (cites: ev-07f63b27cb8d, run-8569a0c92975, ev-2b9b66273c84)
