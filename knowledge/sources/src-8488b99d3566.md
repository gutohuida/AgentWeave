## Lessons

- pytest's default junit_family is xunit2, whose testcases carry no file attribute; this repo's check settings use xunit1 so each failing test has a file. (cites: ev-245a6843bc75, ckpt-09ed8d1f1163)
- In this repo, hub/tests/conftest.py groups tests for xdist loadgroup, which appends '@<file>' to test names in parallel runs; any report-based id scheme must strip it so full-run and re-run ids match. (cites: ev-245a6843bc75)
- The operator's live hub-tests check runs only at landing, so a task's own pre-review checks reach Hub tests only through the sweep set. (cites: q-e15c6d033f60, ckpt-76c0a618c30e)
- The full Hub suite takes roughly 8 to 20 minutes, so acceptance drives should offer a quick mode against a small settings file and run the real suite once at the end. (cites: ckpt-0d79238125d5, chk-77b452d08082)
- After CRWTF-4, a check without report_path and rerun_command is judged as a whole, so the Hub's settings for this repo must match scripts/checks/check_settings.json. (cites: evr-04a160a0c117, ckpt-09ed8d1f1163)
