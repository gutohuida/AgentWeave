## Key decisions

1. Selected `gpt-5.4-mini`, not the nominally cheaper `gpt-5.4-nano`. Nano is listed as the least
   expensive GPT-5.4-class API model, but the installed Codex CLI rejected it when logged in through
   ChatGPT. `gpt-5.4-mini` was the least expensive weak model verified end to end in this actual
   authentication environment.
2. Kept `yolo: false`. This is the safer default for an interactive local coding agent and the Hub
   direct-run smoke test passes with it. The doctor's yolo warning applies to autonomous
   watchdog/MCP prompting; the watchdog is intentionally stopped.
3. Used a single principal Codex agent with role `implementer`. Additional agents and roles remain
   commented examples in the generated YAML so the fresh Hub has the smallest useful surface.
4. Used the native Hub only; Docker was excluded because the user explicitly said it no longer
   matters.
5. Started the source-checkout Hub from `hub/`. Starting it from the repository root timed out in
   the CLI health check, while the same command from `hub/` started PID 29032 successfully. Treat
   this as a source-tree current-working-directory bug, not as an installation instruction to hide.
6. Left the generated `.claude/skills/aw-spec-reindex/` files untracked rather than silently adding
   unrelated Claude skill content to the Codex scaffold commit.
