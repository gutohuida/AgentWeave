### F274 (A) — a turn's outcome is erased by work in the agent's *other* conversations

The finding of the window. Filed at `scripts/drive/FINDINGS.md:18726`, and the index paragraph is
updated with it, so the open severity-A list now reads **three — F271, F188, F274**.

`AgentTimeline` reads both the terminal label (`:237`) and the `Worked for Ns` line (`:280`) out of
`runs[turn.runId]`. That map comes from the timeline route, which truncates its merged events to
**fifty** (`hub/hub/api/v1/agents.py:802-803`) and keys the map off the survivors. The **turns** come
from the conversation-scoped chat history. The fifty events are **agent-scoped**: every conversation
that agent has ever had competes for the same fifty slots.

Driven, in this order, on one agent:

- stop a turn after 6s → browser shows `Worked for 6s` / `Turn stopped · 09:08`. Correct, and this
  is exactly what phases 6 and 7 verified.
- four ordinary triggers on the **same agent in four other conversations**, touching nothing in the
  first one → `run-d8b98481b31b` is no longer in the map, and the same conversation reloads as
  **1 turn boundary, 0 terminal labels, 0 stat lines**. A single operator message on an empty page.

That is F190's opening sentence, restored: *a turn killed mid-sentence is indistinguishable from a
turn that simply had nothing to say* — reproduced live against the change that closed F190. The same
thing happens inside one conversation once it holds enough turns: measured **12 turns on screen, 10
terminal labels, 10 stat lines**.

**The route is not in breach.** `agent-stream-events` spec `:363-366` says in as many words that runs
outside the returned window get no entry, and *The run facts cover every run the events name*
(`:368`) holds — all ten are present. What no requirement says is that **the events must cover the
turns the client renders**. Two queries, two scopes, two bounds, and nothing joining them.

The three rounds argued the run query hard and got it right — round 2's size bound, round 3
correctly replacing it with a lookup by id, `design.md:323-335` on `reconcile_interrupted_runs`
skewing recency. Every step of that survives. The argument was simply bounded by the event window it
inherited. Not the 2026-08-28 lesson (an argument wrong about right things) but its neighbour: **an
