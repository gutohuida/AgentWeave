### What the drive found — F306 (A), filed, not fixed

**The reviewer it staffed was the agent that wrote the code.** `r7af142d` did the work on an unbound
turn, recorded `implementation` evidence naming the task (`ev-c75844228ecc`, `actor_kind='agent'`,
`review_state='accepted'`, on a run whose `task_id` is NULL), and then approved its own work at
sequence 19.

`agents_that_may_have_authored` is the union of exactly three sources — transitions, `assignee`,
runs bound to the task — and all three were legitimately empty. **The evidence table is a fourth
record and it is not read.** By the function's own stated principle (*"a record associating an agent
with a task is sufficient to exclude it"*) it is the strongest of the four: the other three are
circumstantial, while an accepted implementation evidence row is the agent asserting *this is my
implementation of this task*, carrying the very commit the reviewer is handed.
`_guard_author_is_not_reviewer` misses it too, for the same reason — it compares
`agent_that_completed`, which an operator completion leaves NULL.

The branch that produced it **says in its own comment that this must not happen**
(`scheduler.py:1566-1571`): *"`exclude=set()` is a self-approval route … So the ladder gets every
agent any record associates with the task."* The widening returned `set()` anyway. It is not wrong,
it is incomplete — and where it is incomplete it is indistinguishable from not having been done.

Severity **A**: it fails *open* and silently, which is what separates it from `F167` (B), the
adjacent residual on the same repair that fails closed. **Not fixed here** — it changes who may
review a task, so it needs the round discipline and this window does not write proposals. It is day
window material and lands in front of that window through `git diff` on `FINDINGS.md`, which its
playbook reads at step 3. Queued as a note, not as work.

**A truly untouched task is unaffected**: `POST /spec/evidence` records as `Actor(kind="operator")`,
so an operator can supply the commit-naming evidence the review arm requires with no agent involved,
and there the empty exclusion is correct. The defect is the case where the evidence came from an
agent and nothing else did.
