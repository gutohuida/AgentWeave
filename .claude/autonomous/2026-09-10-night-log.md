The comment (§1.3) answers the question the task named rather than restating the code: *how can you
be sure nothing nearer runs after us*. Because the listener is on `document` in the bubble phase, it
is structurally the last handler in the propagation path — every React handler in the tree and every
capture-phase listener anywhere has already run by the time it is called, so there is no owner that
could claim the key after it and be missed by the flag. The same paragraph says why capture would
break the check rather than merely why the phase was kept: moving to capture would put the hook
*ahead* of the nested owners it defers to, and the condition would read a flag nobody had set yet.
