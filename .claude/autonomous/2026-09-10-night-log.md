Added as `D3`, in the existing escape harness (no third file). The gesture it does **not** make is
the leg: it opens the project modal, types a path, opens the in-Hub directory browser, and presses

in-Hub browser is behind the `Browse within the Hub instead` link beside it. The leg clicks the
link; a leg that clicked `Browse…` would have hung the run rather than failed it. That is written
into the code comment, not just here.

The probe reads the mechanism directly rather than inferring it:

    [browser just opened — nothing clicked inside it]
        focus={"tag": "BUTTON", "text": "Hide the in-Hub browser", ... "dialogs": 2}

Escape with React's `onKeyDown` on its own root, so its `preventDefault()` cannot run while focus
sits on the control that opened it. Nothing claims the key, `useDialogFocus` sees an unclaimed
Escape on `document`, and the operator loses the modal **and the path they typed**.
