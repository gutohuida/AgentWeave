# AgentWeave Examples

**Nothing in this directory works with the current product.**

The examples here were written for the retired file-based CLI and Python API (`Session`, `Task`,
`Message`, `MessageBus`, `agentweave init`, `agentweave task`, `agentweave msg`). That surface was
deleted when the Hub became the only way to use AgentWeave. The two Python examples were removed on
2026-09-21 (F405) because both raised `ImportError` on their first line. `cli_session.sh` and
`cli_session.bat` still call commands that no longer exist.

To start using AgentWeave, run bare `agentweave` from a project directory. See
[Installation](../docs/getting-started/installation.md).
